# 2-minute demo script

Record with Loom or QuickTime at 1280×800. Sign in first, and run one question beforehand so you know how long it takes.

| Time | Show | Say (roughly) |
|---|---|---|
| 0:00–0:15 | Landing page | "Students and analysts need country comparisons they can cite. Chatbots are fast but can invent numbers. TrendLens answers with real World Bank data and checks every number the AI writes." |
| 0:15–0:45 | **Ask**: type *"Compare inflation in Australia, New Zealand and the United States over the last 15 years"* → Build report | "Claude turns my question into a query plan: countries, indicators and years from a catalog of real World Bank codes. Then the app fetches the actual data." |
| 0:45–1:25 | Report: headline → insights with ✓ verified badges → "100% verified" → chart → stats table → source link | "The statistics are computed in tested code, not by the AI. Claude writes the insights only from those numbers, and a verifier checks every figure. Anything not in the data gets flagged." |
| 1:25–1:40 | Click **Copy share link**, then **Download CSV**; open the link in an incognito window | "I can share the report with my group or professor. No account is needed to view it, and the data comes along as a CSV." |
| 1:40–1:52 | **Explore**: add Japan, switch the indicator to *Aged 65+* | "Explore lets anyone chart any of 32 indicators for 200+ economies, with no AI cost." |
| 1:52–2:00 | GitHub → Actions tab green | "It's deployed on Vercel, and CI runs lint, types, 29 unit tests and a build on every push." |
